Regex (regular expression) is a short pattern that finds or checks text.

Use this tool in 3 steps:

  1. Type a pattern in the box above (the rule).
  2. Paste a test string on the left (the text to check).
  3. Watch the Match Result update as you type — or click Test.
Try these first

Click a button to load a working example. Then change the text or pattern and see what happens.

Build a pattern in 4 steps

Goal: match dates like 2026-03-14.

  1. Write the shape with placeholders: 0000-00-00
  2. Swap each digit for \d: \d\d\d\d-\d\d-\d\d
  3. Shorten repeats with counts: \d{4}-\d{2}-\d{2}
  4. Lock the whole string with ^ and $: ^\d{4}-\d{2}-\d{2}$

Tip: Start tiny. Get one piece working, then add the next rule.

Cheat sheet
Write this It means
\dAny digit 0-9
\wLetter, digit, or _
\sSpace, tab, or newline
.Any single character
[abc]One of a, b, or c
[a-z]One lowercase letter
[^0-9]Anything that is not a digit
*Zero or more of the thing before
+One or more of the thing before
?Optional (zero or one)
{3}Exactly 3 times
{2,5}From 2 to 5 times
^Start of the text
$End of the text
(...)Capture this part for later
a|bMatch a or b
Flags (optional)

Put these letters in the Flags box:

iIgnore uppercase vs lowercase
gFind all matches, not just the first
mTreat each line as its own start/end (^ / $)

Example: pattern error with flag gi finds every error / Error / ERROR.

Common beginner mistakes
  • Forgot ^ and $ — without them, the pattern can match in the middle of the text.
  • Special characters need escaping — to match a real dot, write \. not .
  • Spaces count — a space in the pattern must also appear in the text.
  • Start simple — if nothing matches, delete half the pattern and test again.
